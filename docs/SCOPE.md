# Scope

## In Scope
- Local authentication and Google OAuth.
- Friend chat/DMs via STOMP WebSockets.
- Channels supporting text chat, LiveKit video calls, and memory features.
- Audio transcription via Deepgram.
- AI Memory system using RAG against local pgvector database.

## Out of Scope
- **Global Chat**: Has been explicitly removed and should not be reintroduced.
- **Phone/SMS OTP**: Has been explicitly removed in favor of Email OTP.
- Documents or task management.
- External application integrations (e.g., Slack, Jira, Google Docs).
